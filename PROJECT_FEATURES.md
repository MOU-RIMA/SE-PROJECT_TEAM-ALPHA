# Project Features

The following features have been implemented in the Student structure:

* **Student ID:** Stored as `studentId` for better clarity.
* **Student Name:** Stored as `studentName` with an increased capacity of 100 characters.
* **Age:** Added `age` field to track student's age.
* **CGPA:** Added `cgpa` field to track academic performance.
* **Department:** Added `department` field (capacity: 50 characters).
* **Contact Details:** 
  * Added `email` field (capacity: 100 characters).
  * Added `phone` number field with an increased capacity of 25 characters.
  * Added `address` field with an increased capacity of 200 characters.
* **Personal Details:** Added `gender` field (capacity: 10 characters).
* **Academic Details:** 
  * Added `semester` field.
  * Added `creditHours` field.
* **Student Status:** Added `status` field (capacity: 20 characters) to represent Active, Inactive, or Graduated.
